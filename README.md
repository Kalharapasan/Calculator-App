# 📱 Calculator App  

This is my **first Android project** – a simple **Calculator App** built using Java and XML in Android Studio.  
It is designed to perform basic arithmetic operations quickly and easily with a clean and simple interface.  

![Calculator App Screenshot](https://github.com/user-attachments/assets/7a152fb2-472c-45e8-a21e-2f7a75b84dc8)

---

## 📝 About This Project  
The main purpose of this app was to learn the basics of Android development, UI design, and Java programming.  
It serves as a starting point for my journey into mobile app development.  

---

## ✨ Features  
- ✅ Simple and user-friendly interface  
- ✅ Perform basic arithmetic operations (Addition, Subtraction, Multiplication, Division)  
- ✅ Lightweight and fast performance  
- ✅ Works on most Android devices (phones & tablets)  
- ✅ Responsive layout for different screen sizes  

---

## 🛠 Technologies Used  
- **Programming Language:** Java  
- **UI Layouts:** XML  
- **IDE:** Android Studio  
- **Build System:** Gradle  

---

## 📥 Installation  

1. Clone or download this repository:  
   ```bash
   git clone https://github.com/Kalharapasan/Calculator-App.git
   ```
2. Open the project folder in **Android Studio**.  
3. Allow Gradle to sync automatically.  
4. Build and run the app on your emulator or Android device.  

---

## 🚀 How to Use  
1. Launch the app on your Android device.  
2. Enter numbers using the keypad.  
3. Select the operation (+, -, ×, ÷).  
4. Press `=` to view the result.  
5. Use `C` or `AC` to clear inputs.  

---

## 🔧 Requirements  
- Android Studio installed on your PC  
- Android 5.0 (Lollipop) or higher for running the app on a device/emulator
